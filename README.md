# Aveloz Showroom - Digital Experience

Este é um projeto de Showroom Digital desenvolvido para a **Aveloz Têxtil**, focado em alta conversão, humanização do atendimento e manutenção simplificada.

## 🚀 Live Demo
[Acesse o projeto aqui](https://allandevindie.github.io/showroom-aveloz/)
[Landing page do projeto](https://allandevindie.github.io/showroom-aveloz/lp.html)
## 🚀 Tecnologias Utilizadas
- HTML5 / CSS3 (Design Premium & Responsivo)
- Google Fonts (Inter)
- FontAwesome (Ícones)
- Integração com YouTube API (Playlists)
- WhatsApp API (Conversão Direta)

## 🛠️ Como dar Manutenção (Sem Código)

### 1. Atualizar Vídeos (YouTube)
Para mudar os vídeos do showroom, você não precisa mexer na estrutura do site. Basta:
1.  Acessar sua conta no YouTube.
2.  Adicionar ou remover vídeos da sua **Playlist**.
3.  O site atualizará automaticamente o conteúdo do player.
*Caso queira trocar a playlist inteira, mude o ID após `list=` no arquivo `index.html`.*

### 2. Atualizar Novidades (Instagram)
O site possui um espaço reservado para um Widget de Instagram. Recomendamos o uso do **Behold.so** ou **Elfsight**.
1.  Crie uma conta gratuita em uma dessas plataformas.
2.  Conecte o Instagram da Aveloz.
3.  Copie o código gerado e cole no lugar do `div.insta-placeholder` no `index.html`.

### 3. Alterar Vendedores
Os dados dos vendedores estão no arquivo `vendedores.html`. Para mudar um número ou nome, basta localizar o bloco correspondente e editar o texto e o link do WhatsApp.

## 📁 Estrutura de Arquivos
- `index.html`: Página principal (Showroom & Novidades).
- `vendedores.html`: Hub de atendimento personalizado.
- `css/style.css`: Estilização global e identidade visual.
